# Resili

Resili is a production-ready TypeScript resilience toolkit for modern Node.js applications.

This repository is currently scaffolded for project infrastructure only. Resilience features must be implemented from the contracts in `docs/ARCHITECTURE.md` and `docs/API_SPECIFICATION.md`.

## Development

```bash
pnpm install
pnpm build
pnpm test
pnpm lint
pnpm typecheck
```

## Packages

- `@resili/core` — core package entry point and future public API surface.
